# RepoGuard

Installation Command: 
`uv tool install --force --python 3.13 "git+https://github.com/vaideesh-siva06/repo-guard.git@development"`

Run Command:
`repoguard chat`

Uninstallation Command:
`uv tool uninstall repoguard`

Note: Please make sure Ollama is installed. Get it at https://ollama.com/download
